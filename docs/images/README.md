# Screenshot shot list

The README expects three images in this folder. Save them as PNG, with these exact
filenames (lowercase), and they will appear automatically.

### 1. `panel.png` — the control panel

The EQ Importer control panel with a block selected and filter data pasted in, before
pressing Apply. This is the first thing anyone sees, so it should look populated rather
than empty. Capture just the plugin panel, not the whole Designer window.

### 2. `dry-run.png` — the Dry Run preview

Dry Run ticked, Apply pressed, showing the band-by-band table in the status pane. The
useful part is the columns — frequency, gain, Q, and the octave width — so make sure
enough rows are visible to show the pattern.

### 3. `applied.png` — verification after a real import

Dry Run unticked, Apply pressed, showing the "All N bands verified" confirmation and the
fresh re-read line. If you can get a shot where the EQ block's response curve is visible
alongside the panel, that's even better.

---

Tips:

- Crop to the panel. A full-screen 4K capture makes the README scroll forever.
- Windows: `Win + Shift + S` for a region capture.
- Anything client-identifying in a block name is worth renaming before you shoot.
